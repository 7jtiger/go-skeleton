DM Chat 테스트 페이지

WS 엔드포인트: GET /dm/v01/ws (JWT 인증 필수 — Authorization 헤더로 전달)
방 생성: POST /dm/v01/mkroom/:pid (pid = 상대방 UID, URL 경로 파라미터)
방 목록: GET /dm/v01/list/:page (JWT 인증 기반, 응답: {totalcount, rooms})
총 unread: GET /dm/v01/total/unread (JWT 인증 기반, 응답: {total, rooms})
메시지 프로토콜: ChatMessage JSON (type: text-message, msg-ack, typing, read-receipt, call-* 등)
점선 칸은 아직 DB에 없는 로컬 준비 방입니다. 첫 메시지 전송 또는 POST /dm/v01/mkroom/:pid 성공 후 서버에 반영됩니다.
